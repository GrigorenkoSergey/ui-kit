Атрибуты

  • name - имя. Необходимо, для передачи во внутренний input. Неотслеживаемое (изменение не вызовет перерисовку элемента).
  • label - метка (легенда). Название поля. Неотслеживаемое
  • open - состояние открыт/закрыт
  • value - выбранное значение в поле ввода

Базовый вариант

Поддерживает фильтрацию, выделение с клавиатуры. Для добавления первоначальных опций необходимо их добавить вручную: 

const autocomplete = document.querySelector("custom-autocomplete");
autocomplete.options = [
  {value: "Опция-1"}, 
  {value: "Опция-2"},
  {value: "Опция-3"},
  {value: "Опция-4"}, 
  {value: "Опция-5"},
];

Кол-во рендеров: 0

Кастомизированные опции

По умолчанию компонент принимает простейшие опции вида {value: string, label?: string}[]. Однако, список можно настроить дополнительно. Для этого нужно переопределить метод element.renderLi. Функция принимает элемент опции, и должна вернуть DOM-элемент списка LI с нужными атрибутами data-value, по которому будет осуществлена фильтрация и выбор. Остальные атрибуты, которые указаны в шаблоне (напр. id), тоже должны быть вычислены.

Пример: 

const withCustomizedLi = document.querySelector(".customized-li");

withCustomizedLi.renderLi = (option, index) => {
  const {value, wiki} = option;

  const li = document.createElement("li");
  li.setAttribute("data-value", value);
  li.innerHTML = `${value} <a href="${wiki}" target="_blank" part="link">?</a>`;
  li.id = `option-${index}`;
  li.role = "option";

  return li;
};

withCustomizedLi.options = [
  {
    value: "Винни-Пух",
    wiki: "https://en.wikipedia.org/wiki/Winnie-the-Pooh",
  },
  {
    value: "Пятачок",
    wiki: "https://en.wikipedia.org/wiki/Piglet_(Winnie-the-Pooh)",
  },
  {
    value: "Иа",
    wiki: "https://en.wikipedia.org/wiki/Eeyore",
  },
  {
    value: "Сова",
    wiki: "https://en.wikipedia.org/wiki/Owl_(Winnie-the-Pooh)",
  },
  {
    value: "Кролик",
    wiki: "https://en.wikipedia.org/wiki/Rabbit_(Winnie-the-Pooh)",
  },
];
